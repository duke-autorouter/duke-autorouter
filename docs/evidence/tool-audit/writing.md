# Welcome to the Neighborhood Tool Library

Borrow the tools you need for small projects, repairs, and everyday jobs. We’re glad you’re here.

## Before you visit

- We’re open **Saturday, 9:00 a.m.–1:00 p.m.**
- Annual membership costs **$20**.
- Members may borrow **up to two tools for seven days**.
- There is **no online booking**. Please visit during open hours to see what is available.

## When you borrow

Choose up to two tools and keep them for seven days. Please return every tool **clean**. If a tool is damaged, report it to the **volunteer desk**.

## First-visit checklist

- [ ] Visit on Saturday between 9:00 a.m. and 1:00 p.m.
- [ ] Sign up for annual membership ($20).
- [ ] Choose no more than two tools.
- [ ] Note the seven-day return period.
- [ ] Ask at the volunteer desk if a tool is damaged.
- [ ] Plan to return borrowed tools clean.
- [ ] Remember that tools cannot be booked online.

We look forward to helping you get started.
