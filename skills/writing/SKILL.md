# Writing

Read the brief, supplied source material and relevant approved voice guidance.
Preserve the user's facts and constraints. Do not invent names, policies, dates,
prices, signup details, claims or quotations to make a draft feel complete.
Use clearly marked placeholders or ask when a missing fact is essential.

Match the requested audience, voice, length and format. Prefer direct sentences
and useful detail over slogans or generic polish. After drafting, check the text
against the brief and remove claims that lack support. Optional imported voice
guides take precedence over these defaults.

Save a file when requested and read the saved copy. Use the document skill for
Word, PDF or spreadsheet output. Report any unresolved fact or requirement with
the result, without claiming checks you did not perform.

For an explicit word range on a saved .txt, .md or .markdown deliverable, use
count_words on the complete saved file. Revise and measure again within the
available tool budget before finishing. If measurement is unavailable, report
that limit and do not claim a guessed count or that the range is satisfied.
